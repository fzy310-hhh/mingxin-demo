3 分钟接入 ​

路线 A：复制提示词（最常见） ​

适合：ChatGPT、Claude、豆包、Kimi、元宝等能联网/能打开链接的 Agent。

  1. 打开你的 Agent。
  2. 复制下面的提示词。
  3. 把域名换成你的站点域名。
  4. 问一句：“2024 级国新系培养方案有哪些学分模块？”
  5. 看它有没有附上页面链接；没有链接就要求它“先读 index.json，再回答”。
text
你是我的“国新学伴”学习助手。请先读取这个索引：
https://guoxin.wxr535.cn/agent/index.json

工作规则：
1. 先读索引，再决定读哪个页面；不要凭记忆回答。
2. 回答时附上你读过的页面链接。
3. 如果索引/页面打不开，直接说“打不开”，不要编造。
4. 涉及培养方案、推免资格等关键政策，提醒我以学院/教务最新通知为准。
5. 不要输出任何个人隐私信息。

路线 B：上传内容包（不能联网时） ​

适合：只能上传文件/知识库的 Agent。

  1. 打开 内容包 content.md（或右键另存为）。
  2. 上传到 Agent 的知识库/文件区。
  3. 用上面的提示词，但把“请先读取索引”改成“请先读我上传的 content.md”。
  4. 问问题时要求它“引用标题 + 链接”。

内容包是什么

content.md 是整站正文的合并版，方便不能联网的 Agent 一次性读取。它可能不是最新；重要信息以页面为准。

路线 C：安装 Skill 包 ​

适合：支持 Skill/插件的客户端（如 Claude Code、DSH、Codex 等）。

  1. 下载 Skill 包。
  2. 解压到客户端的 skills 目录，或在客户端里选择“安装本地 Skill”。
  3. 确认它读取的是 https://guoxin.wxr535.cn/agent/index.json。
  4. 问一句测试问题，检查是否引用来源。

详细说明见 Skill 包。

接入自检清单 ​

  • [ ] 能打开 index.json
  • [ ] 回答里带页面链接
  • [ ] 不知道时会说“没有找到”，而不是编造
  • [ ] 没有输出个人隐私
  • [ ] 关键政策会提醒“以官方为准”

打不开怎么办 ​

  1. 换网络：校园 Wi-Fi / 手机 4G 各试一次。
  2. 把 https:// 换成 http:// 试一次（有些代理会拦截）。
  3. 让 Agent 直接读 content.md，不要读网页。
  4. 还不行：在班级群反馈，或让站长发你一份离线包。
